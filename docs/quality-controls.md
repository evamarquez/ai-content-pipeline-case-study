# Quality controls

## Control register

| Risk | Control |
|---|---|
| Incomplete output | Validate required fields and completion signals before handoff. |
| Weak source coverage | Record sources and keep the evidence boundary visible to the editor. |
| Instruction drift | Carry structured brand context through the relevant stages. |
| Provider variability | Use bounded retries, explicit failed states, and recovery paths. |
| Repetition or weak style | Run revision and humanization before document creation. |
| Unsafe handoff | Attach status, checks, and recovery context to the reviewable document. |

## Human-in-the-loop boundary

The workflow can prepare and check a draft. A person remains responsible for source interpretation, brand fit, factual correction, and publication.

## Measurement rule

A successful request is not proof of a complete article. A saved article is not proof of business impact. The system reports workflow reliability separately from editorial quality and downstream performance.
